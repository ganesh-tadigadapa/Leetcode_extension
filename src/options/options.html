DSA_007 LeetCode Sync — Settings

1. Create a fine-grained GitHub token

The extension talks directly to the GitHub API (no backend). Use a fine-grained personal access token limited to a single repository — it can't touch anything else in your account.

  1. Open GitHub → New fine-grained token.
  2. Repository access: “Only select repositories” → ganesh-tadigadapa/DSA_007.
  3. Repository permissions: Contents → Read and write. (Metadata: Read-only is added automatically.) Leave everything else as “No access”.
  4. Choose an expiration, generate, and paste the token below.

The token is kept only in this browser's local extension storage (chrome.storage.local, not synced to your Google account) and is only sent to api.github.com.
